
# F# Student Management System

A console-based Student Management System developed using F# and SQLite.

## Features
- Add student
- View students
- Update student details
- Delete student
- Show passed students
- SQLite database storage
- Async workflows
- Pattern matching
- List.map and List.filter

## Technologies
- F#
- .NET
- SQLite

## How to Run

Open the project folder in VS Code terminal and run:

```bash
dotnet restore
dotnet run
```

The database file `students.db` is created automatically.
